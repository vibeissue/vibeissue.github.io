Setup rapido

Come iniziare

Tre passi per la CLI. Uno in più se vuoi che l'agente AI apra issue da chat. Funziona su Windows, macOS e Linux — vedi anche Piattaforme.

01

Installa da PyPI

Pacchetto: pypi.org/project/vibeissue.

pip install vibeissue
02

Crea un token GitHub

Personal Access Token con Issues: read & write sul repo target. Dettagli OS: guida token.

03

Metti token e repo in .env

Nella cartella da cui lanci i comandi (il tuo progetto). Il file .env resta gitignored.

GITHUB_TOKEN=github_pat_…
GITHUB_REPO=myorg/my-app

Prova subito:

vibeissue list

Opzionale — percorso completo (agenti AI)

+

Adopt + apri l'agente

Copia skeleton, label, template e regole (AGENTS.md, Cursor, Copilot, Claude). Poi apri il progetto in Cursor / Claude Code / Copilot e dì: «Apri issue per…».

vibeissue-adopt --target ../my-repo --repo myorg/my-app
cd ../my-repo
vibeissue labels --apply

Senza questo passo la CLI funziona; l'agente non sa ancora di dover usare vibeissue.
