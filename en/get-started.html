Quick setup

Get started

Install from PyPI, then wire an AI agent to GitHub Issues on Windows, macOS, or Linux. Cursor, Claude Code, Copilot, and more — see also Platforms.

01

Install from PyPI

One command: get the vibeissue and vibeissue-adopt CLIs. Package: pypi.org/project/vibeissue.

pip install vibeissue
vibeissue --help
02

GitHub token

Create a Personal Access Token with Issues: read & write on the target repository.

Set GITHUB_TOKEN in your environment — see the token guide. Alternatives: .env (gitignored) or .secrets/github_token (one line).

# Verify (after setting the token)
python -c "import os; print('OK' if os.environ.get('GITHUB_TOKEN') else 'MISSING')"
03

Adopt into your project

Copy skeleton, labels, templates, and agent rules into the repo. Also sets the GitHub slug (owner/name).

vibeissue-adopt --target ../my-repo --repo myorg/my-app

# or only the slug if the skeleton is already there
# in .env → GITHUB_REPO=myorg/my-app
04

Labels

From the project folder, apply labels from tracker/labels.yml.

cd ../my-repo
vibeissue labels --apply
05

First issue + AI agent

Test the CLI, then open the project in your agent (Cursor, Claude Code, Copilot, …) — instructions are already in the repo.

vibeissue create "[Bug] Setup test" --labels bug
vibeissue list
